**Recent example — DESI–BEDC:** A source-reconciliation exercise recovered **114 omitted October publication records**, eliminating an apparent **87.5% feeder-coverage growth** trend. The corrected comparison showed **240 distinct published feeder identities in each month and 0.0% growth**. This is a data-assurance finding, **not** a claim about newly commissioned physical feeders.
