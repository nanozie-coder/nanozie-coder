## 📊 Featured Project

### ⚡ Nigeria Power Generation Performance Benchmark

A 24-month Power BI benchmarking analysis comparing **Transcorp Power** with selected Nigerian generation peers using operational performance data published by the **Nigerian Electricity Regulatory Commission (NERC)**.

The project analyses:

- Plant Availability Factor (PAF)
- Available capacity and generation performance
- Load factor and capacity utilisation
- Peer performance benchmarking
- Rolling performance trends
- PAF improvement scenarios
- Potential MW and annual GWh generation uplift

**Key insight:** The analysis indicates that improving capacity availability and reliability represents a larger performance opportunity for Transcorp than utilisation of capacity once available.
